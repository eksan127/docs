## **Main Features**

- 📋 Clipboard enhancements (retention time, item count limits, preview lines, countdown and creation-time labels, order index, and grid columns)
- 🛠️ Custom symbols
- 👣 Inline suggestions
- 🌐 Grammar checker
- 🎨 Key shape selections (Square, Rounded)
- 🔄 Emojis, stickers, GIF tab order
- 🔗 Web clipboard
- 🤖 AI Writing Tools
- 🔍 OCR feature
- 🧩 Custom top row
- ⚙️ Rounded Keyboard Panel

<Tip>
  Tips & Info

  - You can install this GBoard with GBoard official because has renamed package name
  - Mod menu you can access on GBoard Settings \> Patches
</Tip>

## **Lite Features**

- ARM8 only
- 44MB size file
- Detach from Play Store
