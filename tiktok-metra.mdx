## **Features**

- ⚙️ Feed filters
- 🤳 Disable screen capture detection
- 👤 Disable login requirement
- 🔑 Fix Google login
- ⚒️ Feed tab navigation
- ⬇️ Downloads (Video, Images, comment sticker videos/images)
- ▶️ Playback speed
- 🌐 SIM spoof
- 💬 Copy comments without username
- 🔄 Auto Translate comments
- ⏯️ Show seekbar
- ⛔ Detach from Play Store (It will not appear in the update list in the Play Store)

## **How to Login**

You can login using Google Account or you can still use no need to login
