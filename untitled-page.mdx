## What benefit using PotHelper

- Playback start instantly
- No side effect like using Spoof video streams
- All YouTube features are present such as stable volume and multiple audio streams
- This feature is experimental maybe not work for some user and some device

## How to enable to Morphe

1. Download PoToken Helper (PotHelper) on this GitHub

2. Then just Install it and open, no need configure
3. Open YT or YTM, and navigate to<br />_Settings morphe > Miscellaneous > Spoof video streams > disable "spoof video streams" > then click restart app_
4. Now open YT or YTM again then Navigate to<br />_Settings morphe > Miscellaneous > PoToken provider > enable "External PoToken Provider" > then click restart app_
5. Done, and try playing a video

## Troubleshooting

If you get buffering

- Update Microg to the latest version
- Allow PotHelper unrestricted battery usage
